# experiment-prep Skill の入れ方

あアラウド法の実験の前に要る準備を，Claude が Todo リストにしてくれる Skill である．Claude のウェブアプリ（claude.ai）とデスクトップアプリで使える．

## 入れ方

1. このフォルダ（`experiment-prep`）を丸ごと zip にする．zip を開いたときに `experiment-prep` フォルダが 1 つ出てくる形にする
2. claude.ai の設定を開き，Skill の項目（「機能」の中にあることが多い）から zip をアップロードする．画面の名前は変わることがある
3. Skill を使うには，設定で「コードの実行とファイルの作成」を有効にしておく必要がある

## 使い方

Claude に次のように話しかける．

- 「実験をやりたいけど，何から準備すればいい？」
- 「実験の準備リストを作って」
- 「この準備で足りているか見て」（今のリストを貼る）
- 「募集の Slack の文面を作って」

Claude は最初に，研究室の Scrapbox「実験前準備のガイドライン」の本文を貼るよう頼む．ページを開いて本文を全選択（Ctrl+A）し，コピーして貼る．

## リストの保存

- リストは Claude の画面右側にアーティファクトとして出る．チェックや追加の内容は，そのブラウザに保存される
- 別の端末やブラウザからは見えない．ブラウザのデータを消すと消える
- ときどきリスト下の「書き出す」で Markdown を手元に残す．その Markdown を「読み込む」に貼れば元に戻せる
