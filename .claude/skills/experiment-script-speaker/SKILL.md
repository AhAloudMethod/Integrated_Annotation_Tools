# 発声者側の実験説明（台本）を書く

まず，この skill のフォルダと同じ階層にある `experiment-script-common/rules.md`（共通ルール）を読み，それに従う．共通の文面は同じフォルダの `template.txt`，発声者側の部分は `full-template.txt` の `[(* 発声者側]` の部を土台にする．回顧評価があるときは，同じフォルダの `evaluation.md`（評価の説明の書き方）も読み，評価の説明をそれに沿って入れる．

## 聞き取り（発声者側で必ず聞く項目）

共通ルールの項目に加えて，次を依頼に無ければ書く前に聞く．

| 項目 | 扱い |
|---|---|
| プレイの回数と条件（全回同じか，ゲームや設定を変えるか） | 必ず聞く |
| 回顧評価（プレイ直後に本人が自分の録画を評価する）の有無 | 必ず聞く |
| 回顧評価の道具（スプレッドシートか annotator か，annotator ならどの方式か） | 回顧評価があれば必ず聞く |
| 録画の道具（OBS など） | 聞かずにテンプレートの OBS を使う |

## 構成

1. 実験手順の説明（`template.txt` の同意・概要・流れ・同意書・謝礼）．概要の `{役割の課題}` は「実験では[[◯◯◯]]を[[◯◯]]回プレイしていただき、その際の感情を「あ」という声で表現していただきます。」の形にする．回顧評価があれば，その直後に評価することも 1 文で足す．
2. 実験タスクの説明：あアラウド法の説明（`template.txt`）→ 発声者向けのまとめの台詞（`full-template.txt` の 2.1 の続き．見本動画の後の台詞）→ 発声時の注意事項 → ゲームの操作説明 → 回顧評価の説明（あるときだけ．`evaluation.md` の部品 1〜4：評価軸・評価方法・道具の説明・注意事項）→ 質問を聞く
3. 収録：最初の基準音声 → 練習のプレイ（回顧評価があれば，その直後に評価の練習）→ 本番の各プレイの直前の基準音声 → 本番の各プレイ（回顧評価があれば，各プレイの直後に評価と，あればアンケート）．章の頭のメモに 1 回分の手順を番号で並べる（`full-template.txt` の 3 章の頭の形）
4. 事後アンケート・インタビュー・終了・書類（`template.txt`）

## 発声者側の規則

- ゲームの操作説明は，`experiment-script-common/games.txt` にそのゲームの部があれば，その文面を入れる．`[[◯◯]]` の制限時間は，聞き取った 1 回の長さで埋める．`games.txt` に無いゲームは `[[◯◯◯の操作説明]]` のまま残し，報告で一覧にする．複数のゲームを使うなら，各ゲームの部を並べ，どのゲームでも同じ順で読む．
- 発声の教示（声の大きさ・高さ・トーンで表す，できるだけ停止せずに「あ」と発声し続ける）は `full-template.txt` の文面を残す．
- 練習のプレイと，本番の直前の基準音声の収録は，実験者が忘れやすい．実験者はこの台本を進行表として使うので，別のチェックリストは作らず，台本の中で目立たせる．それぞれを独立した節にし，見出しに「ゲームごとに必ず行う」「本番のプレイの直前に毎回必ず行う」と書く．ほかの節（操作説明や本番のプレイ）の中に埋めない．
- 複数のゲームや条件で収録の手順を繰り返すなら，繰り返しを指示する行（「次のゲームの3.2に戻る」など）にも，練習のプレイと基準音声の収録を飛ばさないことを書く．一部のゲームだけにある手順（評価の練習など）は，その節の見出しに「1つ目のゲームだけ」のように書き，ほかの節と区別する．
- 基準音声の録画は本番ごとに録るが，ファイル名は変えさせない（実験の後に回収ツールが試行の名前を付ける．README の「結果の回収」）．回顧評価では，本番の直前に録った基準音声を選ぶ動作を `[* ]` で入れ，名前ではなく日時で選ぶ（直前に撮った 5 秒ほどの録画）ことを実験者向けメモに書く．
- 録画の開始・停止，ヘッドホンをつける，パーティションの後ろに移動する，は台詞と分けて `[* ]` の動作として，その手順を行う位置に書く．
- 回顧評価があるとき，教示は `evaluation.md` の発声者側の列に従う（そのときの自分の感情を振り返って答える）．回顧評価が無ければ，評価軸・評価方法の節は台本から外す（発声者は評価しないため）．
- 回顧評価の説明は，ゲームの操作説明の後，収録の前にまとめて置く．プレイの直後には「録画を見ながら評価してください」の短い台詞と動作だけを置き，説明を繰り返さない．
- 回顧評価で annotator の録画の試行を使うなら，プレイと評価の間に，実験者が録画のファイルを選んで評価区間を合わせる動作を `[* ]` で入れる．
- プレイの直後に評価するときは，ヘッドホンを外す，パーティションから出るなど，評価の席に移る動作も `[* ]` で入れる．
