    実験

    参加者ごとに決めた順で方式と動画を進めます。使い方は README の「実験モード」。

    Space 再生／停止　←→ 前・次の区間へ　Shift+←→ 0.1秒移動　Ctrl+←→ または ,. 1フレーム移動　C 今の時間で区切る（区切れるとき）　H 発声の区間の表示　Ctrl+Z 取り消し　Ctrl+Y やり直し

    視聴（視聴ボタンまたは V）：止まらずに動画を再生します。値の変更はできません。

    聴いてから入力：1区間を再生すると区間の終わりで止まります。Enterまたはボタン0で同じ区間を始めから再生し直し、その間の入力を記録します。区間の終わりで記録を終え、そのまま次の区間に移ります。R でもう一度聴く、Space は記録せずに次へ。

    別ウィンドウ：動画だけを別のウィンドウに出します。ダブルクリックで全画面にできます。別ウィンドウを選んでいてもキー操作できます。

    音声入力：音声で値を入力します。Chromeの方はネット接続が必要です。「快度7」「覚醒度3」「快度7 覚醒度3」、または数字2つ「7 3」（快度・覚醒度の順）。1軸ずつ評価する方式では数字1つでも認識します。「再生」「停止」でも操作できます。値は話し始めた時刻に入力されます。「12秒 快度7」「1分5秒 7 3」のように時刻を言うと、その時刻に入ります。

    コントローラー：ジョイスティックやスライダーをつなぐことができます。AffectRankは、スティックを大きく倒した方向が1回入ります。RankTrace ではスティックの上下で、倒した量に応じた速さで値が動きます。スライダーはスロットル位置がそのまま値になります。

    グラフ：評価グラフを表示します。設定の「グラフをなぞって値を編集する」がオンなら、左クリックで値を直接描き換えられます。連続の方式では、右クリックで区間の区切りを置く・動かす（右ドラッグ）・消す（区切りの上で右クリック）ことができます。

    入力方式は評価の途中でも切り替えられます。切り替える前の評価は自動保存され、同じ方式に戻すと続きから再開できます。
    「動画を開く」で評価する動画を選んでください。
    動画はPC内でのみ処理されます
